# War for ACME GM Control Panel

Current release: **Version 1.1 — Game-Night Production Build**

## Publish the update

Copy every file and folder from this package into the existing GitHub repository.
Choose **Replace the files in the destination** when Windows asks.

Then in GitHub Desktop:

1. Summary: `Publish War for ACME GM v1.1`
2. Click **Commit to main**
3. Click **Push origin**
4. Wait 1–2 minutes
5. Refresh the GitHub Pages website with **Ctrl + F5**

The website must display the large banner:

**WAR FOR ACME — GAME-NIGHT BUILD v1.1**
