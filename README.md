# War for ACME GM Control Panel

Current release: **v2.2 — Shared Multi-GM Edition**

The website is hosted on GitHub Pages and synchronizes the shared `ACME54` game room through Supabase.

Every GM should:
1. Open the same GitHub Pages address.
2. Enter their GM name.
3. Click **Connect**.
4. Confirm the status says **Connected**.

The browser keeps a local emergency copy, but Supabase is the shared master state while connected.
